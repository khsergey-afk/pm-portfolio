# Чек-лист: доклад pptx

*EN: The presentation deck checklist — automated layout checks with hard geometry numbers, then the
human visual pass and the content rules (message titles, MECE groups, chart-type fit).*

Применяется к результату «доклад pptx», после общего чек-листа.

## Пункты

1. Автопроверка вёрстки и содержимого: картинки вместо диаграмм, диапазоны в числах, сноски,
   числа не из книги расчётов.
2. Вёрстка сверена с жёсткими числами геометрии: поле слайда 1 см; низ шапки 1,25/1,6; кегль
   не ниже 10,5; зазор между блоками 0,3; строка таблицы не ниже 0,27; одна сетка на колоду;
   контраст не ниже 4,5:1.
3. PNG каждого слайда просмотрен глазами — визуальная проверка зоны ответственности человека,
   автора сборки это не заменяет.
4. Заголовок слайда — короткая тема, 2–6 слов.
5. Подзаголовок — только ключевой акцент, не пересказ заголовка.
6. Мысль слайда видна в визуале, без чтения текста.
7. Группы слайдов удовлетворяют принципу MECE (не пересекаются, вместе покрывают тему).
8. График соответствует типу данных.
