# Выбор решения по взвешенным критериям

*EN: How to compare 2–3 options (a system, an operating model, a vendor) and end with one
recommendation — weights agreed before scoring, a sensitivity check, and a "do nothing" baseline.
Based on BABOK v3 (decision analysis) and weighted-criteria selection.*

## Суть

Сравнение вариантов и одна рекомендация. Веса — сумма 100 %, согласуются с заказчиком **до**
оценки. Шкала 1–5 с описанием каждого балла. Итог — взвешенная сумма плюс анализ чувствительности:
меняется ли победитель при сдвиге веса ±10 п.п. Обязательная база сравнения — вариант «ничего
не менять». Оценка — балл + основание (документ, демо, ответ поставщика).

## Порядок

1. **Варианты** — 2–3 реальных + «ничего не менять» как база сравнения.
2. **Критерии** — функции, интеграция, стоимость владения (TCO за 3–5 лет), сроки, риски,
   технологическая независимость, зрелость поставщика; критерии не пересекаются (иначе двойной счёт).
3. **Веса** — сумма 100 %, согласовать с заказчиком до оценки; вес — параметр на листе «Допущения».
4. **Шкала** — 1–5 с описанием каждого балла по критерию («5 — типовой коннектор, 1 — разработка с нуля»).
5. **Оценка** — балл + основание (документ, демо, ответ поставщика).
6. **Итог** — взвешенная сумма; анализ чувствительности — меняется ли победитель при весе ±10 п.п.
7. **Рекомендация** — один вариант, почему он, при каких условиях выбор меняется, 1–2 риска.

## Книга Excel — листы

Описание · Допущения (веса, шкалы) · Оценка (формулы `СУММПРОИЗВ`) · Чувствительность · TCO.

## Типичные ошибки

- Веса подогнаны после оценки.
- Стоимость только лицензий — без внедрения, сопровождения и доработок.
- Нет варианта «ничего не менять» — не видно, окупается ли изменение вообще.
